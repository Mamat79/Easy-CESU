# Easy CESU 3.1.0

Easy CESU 3.1.0 ajoute un accès simple et discret à son projet public.

## Téléchargements

- `EasyCESU-Setup-x64-3.1.0.exe` : Windows 11 x64.
- `EasyCESU-macOS-Apple-Silicon-3.1.0.dmg` : Mac M1, M2, M3, M4 et suivants.
- `EasyCESU-macOS-Intel-3.1.0.dmg` : Mac Intel.
- `Easy_CESU_V3_Notice_Installation_et_Utilisation.pdf` : notice en français.

## Nouveautés

- Section `Aide et communauté` dans les réglages.
- Accès au code source, à la documentation et au signalement d'un problème.
- Possibilité de mettre une étoile au projet GitHub.
- Soutien PayPal facultatif, sans abonnement ni fonctionnalité réservée.
- Rappel discret après 30 jours, limité à une fois tous les 90 jours et
  désactivable définitivement.
- Ouverture des liens autorisés dans le navigateur système.

## Mise à jour

L'installateur Windows remplace le logiciel existant sans supprimer la
configuration, les comptes, les clients ni les interventions.

Sur macOS, remplacer l'application dans `Applications`. Les données restent
dans `~/Library/Application Support/EasyCESU`.

## Confidentialité

Aucun paiement n'est traité dans Easy CESU. L'application ouvre uniquement les
pages publiques GitHub ou PayPal validées. Le rappel est enregistré localement.
