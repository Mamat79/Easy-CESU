# Easy CESU 3.1.2

Cette mise à jour améliore l'affichage sur les ordinateurs utilisant la mise à
l'échelle de Windows, notamment les écrans Full HD réglés à 125 %.

## Nouveautés

- réglage `Affichage` directement accessible dans la barre de navigation ;
- modes Automatique, Compact, Normal et Agrandi ;
- compensation automatique du 125 % Windows sur les écrans Full HD ;
- choix mémorisé séparément sur chaque ordinateur ;
- aucune modification de la base de données ni des réglages partagés.

## Téléchargements

- `EasyCESU-Setup-x64-3.1.2.exe` : Windows 11 x64.
- `EasyCESU-macOS-Apple-Silicon-3.1.2.dmg` : Mac M1, M2, M3, M4 et suivants.
- `EasyCESU-macOS-Intel-3.1.2.dmg` : Mac Intel.
- `Easy_CESU_V3_Notice_Installation_et_Utilisation.pdf` : notice complète.

L'installation remplace la version précédente sans supprimer la configuration
ni la base de données.
