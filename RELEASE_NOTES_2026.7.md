# Easy CESU 2026.7

La page Interventions peut désormais afficher une seule ligne par client.

- Le bouton **Regrouper les interventions** réunit les interventions affichées par client, avec leur nombre, la durée totale et le montant total.
- Chaque montant est additionné avec le tarif enregistré pour l'intervention correspondante.
- Les cases **Transmis**, **Déclaré** et **Payé** de la ligne appliquent le statut à toutes les interventions représentées pour ce client.
- Une case partiellement cochée signale des statuts différents au sein du groupe. Cliquez dessus pour cocher toutes les interventions du groupe.
- Le mois et la recherche limitent les interventions concernées. Les cases en tête de colonne restent utilisables pour l'ensemble des interventions affichées.
- **Afficher les interventions détaillées** retrouve les lignes individuelles, avec leurs statuts enregistrés.

Chaque intervention conserve sa date, sa durée, son tarif, son montant et son historique. Les notes et les bilans conservent leurs calculs habituels.

## Installation et mise à jour

La version 2026.7 est disponible pour Windows 11 x64. Les paquets Mac 2026.7 sont en préparation. L'installateur Windows peut être téléchargé directement depuis cette page ; la mise à jour automatique sera proposée lorsque les paquets Windows et Mac seront tous disponibles.

Pour une première installation ou une version plus ancienne, utilisez l'installateur adapté à votre ordinateur. Les comptes, interventions, réglages et licences sont conservés. Les applications Mac ne sont pas notarisées par Apple.
