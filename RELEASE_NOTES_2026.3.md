# Easy CESU 2026.3

Cette version Windows ajoute la prise en charge rétrocompatible des licences
V2 sans modifier les licences permanentes déjà distribuées.

- Les anciens codes `ECP1` et `ECF1` V1 restent portables, permanents et
  vérifiés hors ligne.
- Une licence V2 demande Internet lors de sa première activation et autorise
  trois installations par défaut.
- Après activation, Easy CESU vérifie localement le reçu signé et fonctionne
  hors ligne.
- **Désactiver cet ordinateur** libère une installation avant un changement de
  PC.
- Copier uniquement le code ou le fichier local ne copie pas l'activation V2.
- L'essai reste gratuit pendant 30 jours et toutes les fonctions restent
  accessibles ensuite ; la licence supprime seulement le rappel refermable.
- Le tarif reste un paiement unique de **29 € TTC** via Stripe.

Les versions macOS publiques restent en 2026.2. La boutique Stripe continue
donc d'émettre le format V1 compatible avec les deux systèmes jusqu'à la
publication et la validation d'une version macOS V2 signée.

La mise à jour Windows conserve les comptes, clients, interventions,
documents, réglages et licences existantes.
