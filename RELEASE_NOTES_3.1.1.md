# Easy CESU 3.1.1

Cette correction remplace la redirection PayPal inadaptée par un QR code
affiché directement dans l'application.

## Téléchargements

- `EasyCESU-Setup-x64-3.1.1.exe` : Windows 11 x64.
- `EasyCESU-macOS-Apple-Silicon-3.1.1.dmg` : Mac M1, M2, M3, M4 et suivants.
- `EasyCESU-macOS-Intel-3.1.1.dmg` : Mac Intel.
- `Easy_CESU_V3_Notice_Installation_et_Utilisation.pdf` : notice en français.

## Correction

- `Soutenir Easy CESU` affiche le QR PayPal dans une fenêtre intégrée.
- La même fenêtre propose le lien PayPal.Me utilisable sur ordinateur.
- Le rappel facultatif ouvre cette même fenêtre.
- Aucune page PayPal trompeuse n'est ouverte dans le navigateur.
- Le QR fourni par Mamat Leroy est inclus dans les applications Windows et
  macOS.

## Mise à jour

L'installateur Windows remplace le logiciel existant sans supprimer la
configuration, les comptes, les clients ni les interventions.

Sur macOS, remplacer l'application dans `Applications`. Les données restent
dans `~/Library/Application Support/EasyCESU`.
