# Easy CESU 2026.6

Easy CESU peut désormais rechercher, télécharger et installer les mises à jour depuis le logiciel.

- Une vérification automatique quotidienne signale les nouvelles versions avec un bandeau discret.
- Réglages > Mises à jour du logiciel permet une recherche manuelle et la désactivation de la recherche automatique.
- Télécharger et installer choisit le paquet adapté à Windows, Mac Apple Silicon ou Mac Intel.
- Le téléchargement est vérifié avant installation. Les comptes et la licence sont sauvegardés avant le remplacement de l'application.
- Easy CESU se ferme puis se relance après installation. Une autorisation de Windows ou macOS peut être demandée.
- Sans connexion, le logiciel reste utilisable ; un téléchargement corrompu ou une sauvegarde échouée empêche l'installation.

Cette version inclut aussi les nouveautés 2026.5 : emails avec copies, sélection de colonnes, navigation dans la relecture et récapitulatif final avec tous les clients retenus cochés par défaut.

## Installation et mise à jour

Installez la version 2026.6 au même emplacement que la version actuelle. Les versions plus anciennes ne possèdent pas encore la recherche intégrée : cette première installation doit utiliser l'installateur téléchargé sur GitHub. Les comptes, interventions, dossiers, réglages et licences restent conservés.

La version 2026.6 existe pour Windows 11 x64, macOS Apple Silicon et macOS Intel. Les applications Mac ne sont pas notarisées par Apple.
