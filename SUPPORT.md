# Soutenir Easy CESU

Easy CESU reste entièrement gratuit et toutes ses fonctions sont disponibles
sans contribution.

Pour soutenir volontairement son développement, scannez ce QR code avec

![QR code PayPal de Mamat Leroy](systeme_notes_intervention/application/static/assets/paypal-support-qr.png)

Le QR code est affiché directement afin d'éviter une redirection PayPal
inadaptée aux navigateurs sur ordinateur. Easy CESU ne traite aucun paiement,
ne reçoit aucune information financière et ne crée aucun abonnement.

Depuis un ordinateur, utilisez directement le lien :

**[Ouvrir PayPal.Me - MamatLeroy](https://www.paypal.com/paypalme/MamatLeroy)**

signalant un problème utile.
